VaultBridge · Offline Document Anonymization & Claude Connector

VaultBridge is an offline macOS application and bundled Model Context Protocol (MCP) server by Quan Dang. It anonymizes documents on your Mac before sharing text with Claude, and restores AI answers locally. About VaultBridge

System Requirements

  • Operating System: macOS 26.0 or later.
  • Hardware: Apple Silicon Mac (M-series, arm64).
  • AI Client: Claude Desktop or the Claude Code CLI.

How to Connect VaultBridge to Claude Desktop

VaultBridge embeds a local stdio MCP server inside the application at Contents/MacOS/vaultbridge-mcp. To connect it to Claude Desktop:

  1. Make sure VaultBridge.app is in your /Applications/ folder.
  2. Open your Claude Desktop configuration file: 
    ~/Library/Application Support/Claude/claude_desktop_config.json
  3. Add the vaultbridge connector to the mcpServers section: 
    {
  "mcpServers": {
    "vaultbridge": {
      "command": "/Applications/VaultBridge.app/Contents/MacOS/vaultbridge-mcp"
    }
  }
}
  4. Restart Claude Desktop. VaultBridge will appear under your active tools.

If you use the Claude Code CLI, register the embedded server with:

claude mcp add -s user vaultbridge -- /Applications/VaultBridge.app/Contents/MacOS/vaultbridge-mcp

Frequently Asked Questions

What does VaultBridge do?

VaultBridge reads PDFs and images on your Mac, extracts selectable text or runs on-device Apple Vision OCR on scans, reconstructs tables into Markdown, scores and routes relevant pages, and detects sensitive values (such as names, dates, phone numbers, addresses, account numbers, and court docket numbers). It replaces those values with placeholders (like [PERSON_1] or [DATE_1]) so you can share AI-ready Markdown with Claude without sending real identifiers.

Can restored personal data leak back to Claude?

No. When you ask Claude to restore an answer via the vault_restore_text MCP tool, the restoration runs entirely on your Mac. The MCP server unmasks the tokens locally and writes the restored plaintext to your macOS clipboard or saves it to a private file in ~/Downloads (with owner-only 0600 permissions). The tool returns only status metadata (such as the number of restored placeholders) to Claude, so real values are never returned to Claude or stored in chat logs.

How do I restore text in the standalone desktop app?

In VaultBridge.app, click the Restore Clipboard button in the toolbar or press ⌘⇧U (Edit → Restore Clipboard). VaultBridge reads text from your macOS clipboard, finds placeholder tokens, substitutes the original values from the app's in-memory vault, and writes the unmasked text back to your clipboard marked with concealed and transient pasteboard types.

Does VaultBridge catch every sensitive value?

No. Detection is automated and is not guaranteed to catch every identifier. Non-standard formatting, unlabelled numbers, out-of-vocabulary names, or health information in unstructured prose can be missed. You must always review the masked Markdown output before sharing it with Claude or external parties.

What file formats are supported?

VaultBridge supports PDF documents (.pdf) and images (.png, .jpg, .jpeg, .tiff, .tif, .heic), including multi-frame TIFF files. Scanned or low-density pages automatically trigger Apple Vision OCR.

Where are my documents and vault mappings stored?

VaultBridge processes files on-device. The application is sandboxed with no network access. Token mappings reside solely in volatile process memory during the active session and are erased when the application or MCP process terminates, or when you clear the vault.
