What it does

  • Save anywhere: Save links via the iOS Share Sheet in Safari or any app without interrupting your reading flow.
  • Smart folder suggestions: Automatic category suggestions analyze link metadata to pick the right folder for each bookmark.
  • Custom folders: Personalize each folder with custom icon glyphs and color swatches.
  • Read and unread tracking: Every new save defaults to unread with a visual indicator. Opening a link marks it as read, and the Inbox displays all unread bookmarks across folders.
  • Tags and notes: Add custom tags and notes to bookmarks for additional context and filtering.
  • Fast search: Search across all saved bookmarks by title, URL, or description.
  • Data backup and export: Export your bookmarks and folders at any time as JSON or universal Netscape HTML bookmark files.
  • Browser extension bridge: Sync bookmarks between your desktop browser and LinkPocket via a dedicated sandbox folder.

Frequently asked questions

How do I save links to LinkPocket?

You can save links through the iOS Share Sheet from Safari and other apps, by copying a link and tapping the paste prompt in LinkPocket, or through the LinkPocket browser extension.

How does category suggestion work?

When you save a link, LinkPocket analyzes the link title, description, and domain to suggest the most relevant folder from your collection using AI categorization or keyword heuristics.

Can I organize folders with custom colors and icons?

Yes. Each folder supports custom icon glyphs and accent color swatches so you can identify categories quickly.

Can I export my bookmarks?

Yes. You can export your full bookmark collection from Settings as a JSON archive or as a Netscape HTML bookmark file compatible with Safari, Chrome, and other desktop browsers.

How do I delete my LinkPocket account?

You can delete your account and all associated bookmarks and folders directly from Settings inside the app.
